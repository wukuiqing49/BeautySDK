# 透明贴纸测试素材

6 张原创扁平风格 PNG：圆框眼镜、爱心眼镜、卷胡子、蓝色礼帽、金色皇冠、猫耳。
由项目脚本 `scripts/create_sticker_samples.py` 使用 Pillow 绘制，非下载素材、非 AI 图片生成结果。
每张 512×256 RGBA，真实透明背景；预览棋盘没有写入素材。

## 定位参数

`manifest.json` 记录文件名、锚点、缩放参照和图片归一化 pivot。

- 眼镜：双眼中点为锚点，双眼距离为单位，整图宽度约为 2.5 倍眼距。
- 胡子：真实上唇为锚点，嘴角距离为单位，整图宽度约为 1.7 倍嘴角距离。
- 帽子、皇冠、猫耳：双眼中点为锚点，pivot.y=1.45 在素材下方，使挂件位于眼睛上方。
- pivot 允许在图片外；这些参数只是测试初始值，需对真人佩戴调整，不代表精确头顶测量。

坐标以素材左上为原点，x 向右、y 向下；使用眼线/嘴角角度旋转，沿用 SDK 对旋转和镜像的处理。
PNG 为非预乘 RGBA；Demo 通过 Bitmap.getPixels 取得非预乘 ARGB，CPU/GL 使用匹配的 source-over，不直接上传默认预乘 Bitmap 内存。

## 当前接入状态

此目录属于 Demo 的 assets，未加入共享 SDK AAR。素材已生成、验证 alpha 并人工检查预览。
已通过 DemoStickerCatalog 按 manifest 读取、缓存并传入共享 StickerPack；CPU/GL 均实现图片定位与 alpha 合成，GL 负责纹理缓存和释放。
静态图和相机页可选择圆框/爱心眼镜，以及礼帽/皇冠/猫耳，胡子用独立开关；选择 MediaPipe 可提供所需锚点。贴纸需要有效的人脸锚点。
已验证公开测试人像的三组 PNG 搭配及六素材 CPU/GL 一致性；这不是实际推流、真实动态遮挡或持续性能验证。
