# Demo 效果与资源体验

本轮仅修改 Android Demo 展示和交互；SDK 资源格式、安装验证、渲染算法及发行契约继续复用现有实现。

## 效果面板

- 分类固定在顶部，横向边缘渐隐提示；预设与微调使用同一面板高度。
- 点击顶部手柄展开/收起浏览区，支持向下拖动关闭；横屏使用右侧面板。
- 预设由 RecyclerView 展示，普通手机默认四列、54dp封面/26dp符号/12sp单行名称；大字体按可用宽度减列。选择立即应用，“无效果”明确关闭当前分类。
- JSON 参数使用48dp高横向选择与单一固定滑杆，不按剩余高度拉伸。切换参数复用滑杆，模型更新同步数值，不重建控件。
- 顶部恢复默认作用于分类；参数区重置仅恢复当前参数的 JSON 默认值。
- 3D 选择仍为 Demo 内置眼镜/礼帽，不属于可导入资源。启用时提示普通贴纸、美型暂停，保留其参数与选择；回到普通贴纸后恢复。
- 关闭重开、切换分类回到预设，保留参数值。

## 资源中心

- 独立页面不创建相机、模型或 GL；顶部提供导入与更多菜单。
- 已安装/在线资源分开展示，普通手机默认三列、80dp封面/32dp符号/13sp最多两行名称，大字体自动减列；横屏合并来源/分类栏。封面解码缓存不进入视频线程。
- 点击卡片打开详情，不改变选择。详情明确使用、停用、删除；删除二次确认，主题应用前说明会影响多个分类。
- 下载/导入只安装，保持当前搭配。完整交付包的默认搭配与旧手势包仍需从更多菜单显式应用。
- 已选择不等于当前人脸上正在渲染：勾选角标表达选择，详情保留完整状态；3D或总开关导致暂停时卡片短标“已暂停”。普通已安装/已选择不再占独立状态行，下载与错误信息仍保留。
- 长按作为快捷入口保留，主要操作均可从详情到达。
- 目录地址、官方资源下载、恢复默认、导入摘要放在更多菜单；取消仅在任务中的更多菜单显示，技术错误在点击说明后查看。
- 未配置在线目录时提供空态及配置入口，不自动联网。

## 验收边界

两种页面内容外边距统一16dp，网格内部间距8dp、行尾间隔12dp，首末列不叠加外侧卡片边距。预设/微调保持同高；竖屏默认面板约42%（至少320dp并按字体适当增加），可手动展开。模式按钮缩小可见底色，但保留48dp点击范围。

检查两台手机的资源卡片、最后一行、详情应用、滑杆稳定、3D 提示与选择记忆；补横屏/字体放大与系统栏检查。只截取界面 View，禁止把相机实时帧写入证据。
字体放大使用 Pixel 8 的实际系统 fontScale=1.3，结束恢复原值；OPPO 的 ADB 写系统字体受限，字体放大单列未验收。旋转通过 UiAutomation 执行，WindowManager 恢复原始模式与方向并核对系统设置。
具体本轮通过项、失败修复及未测项见 `testing/TEST_REPORT.md`，界面回归不代表真人效果或长时性能验收。
