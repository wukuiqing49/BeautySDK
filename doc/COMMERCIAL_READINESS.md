# 商业候选版工作清单

当前事实统一见 [产品状态](PRODUCT_STATUS.md)，最新执行证据见 [测试报告](testing/TEST_REPORT.md)。本文仅列未关闭的交付任务，旧阶段“源码未运行”不再作为当前结论。

## 已建立

- 单 Maven 入口及完整本地仓库、来源摘要检查、独立消费者 Debug/Release/R8。
- 资源统一清单、assets加载、可选发行签名、个人CMS草稿与完整工作区备份。
- [首版范围](../resources/commercial/trial-release.json)、候选与实验能力分级、[首次接入任务卡](FIRST_INTEGRATION.md)。
- JVM签名基线检查与候选打包门禁；不代表完整二进制或行为兼容认证。
- [验收流程](testing/TRIAL_ACCEPTANCE.md)与[发布回退流程](RELEASE_CHECKLIST.md)。

## 待关闭

| 工作 | 完成条件 |
| --- | --- |
| 少量默认预设调校 | 经同意的真人静态/动态评审，无阻断画质缺陷 |
| 多设备长测 | 代表性设备矩阵、显式性能预算及有效人脸负载 |
| 独立GPU宿主 | 实际纹理画面、生命周期及错误恢复验证 |
| 外部接入 | 未参与开发者独立完成任务卡，记录耗时与求助 |
| 正式发行 | 固定发行源、正式密钥、完整签名发行回归 |
| 分发审核 | 模型、素材、依赖来源与分发范围逐项确认 |
| 运行状态 | 模型初始化失败、组件缺失与资源可用状态完整联动 |
| 完整兼容性 | JVM基线之外的Kotlin元数据、native ABI、语义与资源迁移验证 |

CMS保持个人使用；直播厂商及iOS不纳入本次交付。资源发行签名不等于客户付费授权。所有资格保持pending，不能用构建、夹具测试或文档完备替代真实验收。
