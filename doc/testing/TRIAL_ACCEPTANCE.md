# 限定试用验收

当前所有真人质量与多设备资格保持 pending。已有设备夹具和构建结果仅作工程基线。

## 默认预设调校

先评审三组目标：轻自然、柔和人像、低光保守。沿用现有内置参数作为待调样例，不直接升级为已验收预设。每组记录资源 ID/revision、完整 ZIP SHA-256、SDK版本与实际参数。

在经同意的真人现场评审中覆盖不同肤色、年龄段、光线和眼镜条件；静止、说话、闭眼、快速转头、手部遮挡、进出画面。默认不保存图像。逐项记录自然度、肤色偏移、纹理损失、边缘抖动、挂件贴合，评分1～5并备注缺陷。建议至少两名独立评审，每项至少4分、无黑屏/明显变形等阻断缺陷；意见冲突时保留记录并重调，不只取平均分。

## 设备与持续性能

设备矩阵覆盖8～12台，至少含高、中、低档及不同GPU/系统；先确定目标设备范围，再选预算，不把 Pixel 8 单机扩展为所有设备。

使用现有 `CameraStabilitySoakDeviceTest`，明确指定设备序列号、三个模式各3600秒，先由产品负责人确定 `minimumPreviewFps`、`maximumThermalStatus`、`maximumPssGrowthKiB`。示例参数名见源码；不得用随意设置的宽松预算取得通过。

每条记录含设备/GPU/API、分辨率/目标帧率、效果与模型配置、实际时长、有效人脸覆盖率、帧数、内存、热状态和失败信息。人脸组覆盖率至少80%；测不到GPU执行或端到端延迟时写未测，不用CPU提交时间代替。现有夹具不提供完整画质资格。

真实负载需有人或经同意的固定测试输入，不能无人看护地启动相机空跑后宣布通过。保持已有相机数据与用户配置，不使用清数据作为测试前提。

## 生命周期与恢复

切前后摄、横竖屏、裁剪尺寸变化、后台返回、反复进入退出、EGL丢失、新模型失败、资源损坏、取消安装、存储失败；错误后旧效果或明确旁路仍可用，不能黑屏或静默成功。

## 工坊到手机

导出后记录包摘要和参数；手机资源中心显示最近成功导入完整包的同一摘要。先导入再明确应用默认配置，核对分类、名称、选中素材与参数值。摘要只确认包字节一致，不保证当前用户未调参或两端画面一致。网页示意与真人效果分开评审。

## 资格记录

结果写入独立报告并保留源版本、资源摘要、执行日期、评审者和证据。只有完成人工审阅后，才更新 `trial-release.json` 对应 gate 的 status、reviewer、reviewedAt 和 evidence（相对路径、sha256）。失败标为 failed，未执行为 pending。

外部开发者接入使用 [首次接入任务卡](../FIRST_INTEGRATION.md)。正式发布还需分发授权及签名发行审核，不能只凭性能过关。
