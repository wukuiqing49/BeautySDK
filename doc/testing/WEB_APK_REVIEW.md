# Web 与 APK 页面、功能和真机复核 · 2026-10-27

## 结论

两端职责应保持“Web 制作交付 → SDK 安装组合 → APK 实时验证”。本次将27份当前预设同步APK、补齐完整资源库直接导入和显式应用默认配置，并修复真实下载与状态恢复问题。最终Pixel8整组80项通过；不是所有设备、商业画质或持续直播性能验收。

## 已修复

1. 完整资源包页的同源导航拦截了Blob下载，成功文案并不等于实际下载。现在跳过download链接和非HTTP导航；浏览器实得资源库及套装文件并回读校验。
2. 工作台每次切页都更新来源时间，导致交付页自设语言/默认搭配被重置。现在按资源摘要、搭配和默认值形成内容签名，无修改导航保持版本。
3. 主题载入示例/导入/新建仍显示旧工作台来源文字。切换内容时清理来源提示。
4. APK只有17份旧内置，现从Web校验目录显式同步27份，并按目录的摘要和身份安装；保留旧修订，保障已有用户选择。
5. APK不能直接加载Web完整交付ZIP。公共库新增独立交付包解析/预检/批量安装；文件白名单、摘要、封面、身份、默认槽位均校验。失败撤销本批新增项，不放宽原单项解析器。
6. 导入不覆盖当前搭配；新增“应用导入资源库的默认配置”，显式应用后保存语言/默认设置，重开保持；导入任务接入取消。
7. 内置资源删除后重开会自动装回。现在每个内置摘要仅自动安装一次，新修订仍可随包新增。
8. 修正过时测试：资源中心已独立、主画面默认为效果、原“工坊”不再是底部面板；重置等异步IO要等待实际生效。测试还增加状态隔离，避免依赖用户初始参数。
