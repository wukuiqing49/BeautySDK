# 效果面板设计修复 · 2026-10-30

对象为 Android XML 相机 Demo；使用 apple-design 的层级、稳定反馈和适应性原则，保留 Android 底部面板、48dp 触控和系统字体。面板的任务是快速试效果、连续调参数，并始终能返回二维贴纸。

- 导航：分类在第一层，预设/微调在第二层；贴纸用固定的「2D 贴纸 / 3D 贴纸」切换，三维素材才进入横向列表。退出三维不依赖横向列表的滚动位置。
- 卡片：封面、选中描边、点击遮罩统一 12dp 圆角，8dp 列间隔、12dp 行间隔、16dp 页面边线；深色中性底色，不使用浅灰大块底板。图片等比铺满，符号保持独立尺寸。选中用角标和边框，不增加文字行。
- 反馈：点击预设仅一次「已应用」短提示；启用三维仅一次说明。保存忙碌和生效文字不插入相机内容流，错误仍提示，管理页保留总体进度/状态。
- 微调：参数选择、两行固定标签与重置、48dp 滑杆依序排列；滑杆左右各 16dp 内边距，底部留 12dp，空间不足时纵向滚动。保留同一滑杆实例，不因实时数值更新重建。

依据（来自本机 apple-design 参考文件）：`layout.md › Visual hierarchy` 强调对齐、分组与渐进展示；`layout.md › Adaptability` 要求适应尺寸和文字变化；`accessibility.md › Vision` 要求不只用颜色表达状态；`typography.md › Ensuring legibility` 要求可读文字；`feedback.md`、`sheets.md`、`sliders.md` 用于反馈、面板与连续输入的检查。12dp/8dp 等具体尺寸为本项目设计选择，不是 Apple 对 Android 的规范。

验收以 TEST_REPORT.md 为准；仅构建或静态检查不能视为截图观感和真机交互通过。
