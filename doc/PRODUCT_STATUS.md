## 产品与交付

Android 实时视频美颜与素材效果 SDK，配套个人可视化资源工坊。版本 `0.2.0`，阶段为**限定范围试用**，尚未完成商业资格验收。

单一依赖：`com.beautysdk:beautysdk:0.2.0`。当前交付本地 Maven 仓库，内部实现模块仍独立；不是无依赖的合并 AAR。Android API 24+，GPU 主线要求 ES3，宿主管理视频采集、EGL、音频、编码和推流。

- 先前 Pixel 8 独立生成色卡 RGBA 路径已运行；最新单入口版本未完成设备安装，不能混用证据。
