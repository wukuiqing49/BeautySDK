# Demo分辨率测试

入口：相机演示 → 更多 → 分辨率测试。提供640×480（默认4:3）、1280×720和1920×1080（16:9）三个请求档位。选中后真实重绑CameraX并通过原有BeautyEnginePipeline渲染；不是只改标签或拉伸View，也不是强制输出固定像素的缩放模拟。

主画面新增三行请求/实际视频/分析输入尺寸。实际值取SurfaceRequest的逻辑crop和实际投递给分析器的纹理缩小RGBA，CameraX可能协商回退或共同视场裁剪，以实际值为准。改变分辨率不重置用户效果参数；选择保存到Demo私有偏好，页面重建与关闭重开均保留，首次使用默认640×480。前后摄沿用当前请求。重绑使旧检测/分割/手势及统计代次失效，旧帧不跨尺寸显示；原图/全部分析停用时分析尺寸显示不可用。

当前分析支路直接从合成前OES纹理及同一normalize变换生成最长边320的小RGBA，通过双PBO/fence后续帧轮询供人脸、手势和背景分析使用。CameraX独立320×240分析use case保留协商，但不再消费其RGBA。此前仅凭共同ViewPort和宽高比判断视场一致不充分：OPPO高清独立RGBA与实际显示存在约1.33倍尺度差，Pixel也有较小差异。分析输入是模型前的小RGBA尺寸，不等于模型内部Tensor尺寸。

## 前轮分辨率适配验证（2026-10-30，未覆盖实际内容对齐）

GPUPixel磨皮均值支路改用输出短边480为参考，采样间距为4×min(width,height)/480像素。640×480保留原间距，同视场720p/1080p保持相对作用范围；检测小图尺寸不参与计算。不会新增绘制或FBO。旧版本固定像素间距的高清磨皮摘要不能直接作为新版像素基线；锐化等细节滤镜仍有像素尺度，不承诺所有效果完全一致。

诊断区现在受相机画面可用高度约束，可纵向滚动，分辨率文字自然换行。选择由宿主私有偏好保存，不重置美颜/贴纸配置；公共SDK仍不保存Demo页面选择。

最终双机各14项共28次常规回归，加OPPO横屏默认字体、Pixel2.0字体竖屏和横屏3次，共31次设备执行通过。覆盖前后摄三档、快速切换与返回SD、共同视场宽高比、小分析图、原图暂停、重建和新会话记忆、诊断末行可达、既有手势/3D记忆、回调隔离和全部GPUPixel设备用例。最初横屏专项因相机退出后的桌面/锁屏方向前置条件不足失败，测试改为每次重开前唤醒/解锁并重新冻结旋转，保留实际方向与文字断言后通过；不能把首次失败当作通过。

跨尺寸合成纹理使用640×360/1280×720/1920×1080，在同一归一化视场探针比较RGB。OPPO平均误差约0.19/0.15，Pixel约0.20/0.17（0～255）；同时断言磨皮真实改变像素且alpha保留。该测试不采集相机画面，不能替代真人肤质验收。

四模块JVM共178项，177通过、1跳过、0失败。Debug/测试APK、无正式签名Release/R8、lint通过（0错误、214警告）；UI/i18n门禁0警告，架构门禁4项既有独立示例/测量工程提醒。GPUPixel两个ABI的Debug/Release共4份ELF及两份APK静态16KB对齐检查通过。最终Debug已安装到两机，无卸载或pm clear，私有文件/偏好摘要以及专项字体/旋转配置恢复一致；未保存相机画面。

未验收真人跨分辨率肤质/3D闪烁、不同视场和人脸占比的一致观感、长时FPS/温升、其他设备回退矩阵、Release设备运行或16KB页设备运行；不承诺本轮优化提高FPS。OPPO未验证2.0字体，系统明暗主题没有新增完整矩阵。

## 高清静止错位修复验证（2026-10-30，最新）

前轮“共同ViewPort/宽高比一致”未覆盖实际画面内容，用户报告的静止错位成立。当前改为同一原始纹理缩小输入，取消独立CameraX RGBA消费，避免设备相关的尺度差。

OPPO、Pixel前后摄三档共12个内容对齐点均通过，最佳缩放均1:1，相关性分别0.99855～0.99957、0.99969～0.99991。数值仅在RAM从实际分析回调和参考纹理采样比较，不保存相机像素。原表实际视频/分析尺寸保持有效。

本轮双机各28项加3次横屏/字体专项共59次设备执行通过，三模块JVM173通过/1跳过，Debug/androidTest、无正式签名Release/R8、lint及门禁通过；私有文件及专项系统设置恢复一致。初轮息屏/清理异常及160/320采样混叠导致的失败均保留在测试报告，阈值未降低。

同纹理小图存在GPU读回成本，未验证持续性能；真人帽子动态观感仍需验收。详细证据以[最新报告](testing/TEST_REPORT.md)及[本轮结果](testing/evidence/sticker-alignment-final-20261030/results.json)为准，前轮31次执行只为历史适配记录。
