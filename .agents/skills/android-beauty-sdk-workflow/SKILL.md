# BeautySDK 视频帧处理

读取 `.agents/config/project-profile.yml`、`.agents/rules/beauty-sdk.md` 和 `.agents/rules/architecture.md`。当前事实优先于规划。

## 实现路径

1. 查明选定版本的引擎处理回调及交回接口，确认可修改编码前视频；查看真实代码或官方文档，不凭名称猜测观察回调支持写回。
2. 列出输入/输出格式、线程/EGL、旋转/镜像/裁剪、时间戳和资源所有权；确定是否需要 CPU 转换或 GPU 读回。
3. 打通旁路和最小 GL 处理，检查输出分辨率、颜色与远端结果，再接异步检测；不以自行采集的摄像头 Demo 替代引擎集成。
4. 检测使用有界调度和独立有效数据；结果关联采样时间、坐标变换和会话代次，忽略停止后、换摄像头后或过期的回调。
5. 用眼睛/鼻子/嘴部锚点计算挂件位置、角度和比例，检测与输出坐标统一后再做平滑。无有效人脸时隐藏挂件。
6. 明确 FBO/纹理复用、同步、GL 状态恢复、检测器线程和释放顺序，异常按契约回退原帧。

## 验证

- 用确定输入验证旋转镜像、裁剪、stride、结果过期、会话重置和并发释放等逻辑。
- 用设备验证 GL、模型、生命周期与远端实际合成，持续运行时对比不开特效、检测、检测加合成三组；美颜叠加单列。
- 记录转换、推理、渲染、总时延与尾延迟、FPS、内存、温升、配置与运行时长。不用模型体积推断内存、包体或速度。
- 没有设备或引擎凭据时继续可做的库构建和逻辑验证，明确剩余集成验证。
